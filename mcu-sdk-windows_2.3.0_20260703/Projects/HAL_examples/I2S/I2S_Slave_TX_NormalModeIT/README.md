# Description

This is an I2S interface transmit mode using IT example. It use I2S1 interface to transmit data.
The example works with the NXP SGTL5000 audio codec.
The debug information is printed to UART.

## Hardware configuration

I2S1 (PORT1 pins 10, 11, 12, 13) - I2S slave

## Settings

I2S1:
- Mode: slave
